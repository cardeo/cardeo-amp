# Roadmap

Cardeo Amp is currently in Phase 1: project foundation, vision, and
documentation. Playback functionality should not be implemented until this
foundation is in place.

## V1

The first functional version should focus on the smallest useful local music
player experience.

- Local MP3 file picker
- Drag-and-drop support
- Playlists
- Playback controls
- Progress bar
- Volume
- Shuffle and repeat

V1 should prove the core product idea: a fast, focused, local-first player that
works without accounts, subscriptions, cloud services, recommendation
algorithms, or social features.

## Future

Future work should build on the local-first foundation without compromising it.

- ID3 metadata
- Album artwork
- Visualizer
- Desktop app via Tauri
- Theme ecosystem
- Community-created skins

These features should be added only when they support the project's identity:
owned music, local control, speed, simplicity, and personality.
